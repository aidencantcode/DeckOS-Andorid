# 04 — Library setup & ROM scanning

Goal: casual users never write `metadata.pegasus.txt` by hand. Advanced users still can.

## First-run Setup Wizard (controller only, re-runnable: Settings → Library → Run setup again)
1. **Welcome** — language, button layout (auto-detect Xbox/Nintendo face buttons, let user confirm by pressing "the bottom button").
2. **Storage access** — explain, then request **All files access** (`MANAGE_EXTERNAL_STORAGE`; fine because we sideload, not Play Store). If denied → SAF folder picker fallback (slower; warn).
3. **ROM folders** — list storage volumes (internal, SD card, USB) with free space; user picks one or more root folders (e.g. `/storage/XXXX-XXXX/ROMs`). Common roots are suggested automatically if they exist (`ROMs`, `Roms`, `roms`, `Games`, `Emulation/roms`).
4. **System detection** — scan subfolders; show a list: detected system, icon, game count, confidence; toggles; "this folder is actually …" reassign; unknown folders listed separately.
5. **Emulators** — for each enabled system: installed emulators found, recommended default preselected, "Not installed" hint with emulator name (no download links required; optionally open the official site/Play Store page).
6. **Accounts (optional, skippable)** — RetroAchievements, Steam, SteamGridDB, ScreenScraper, IGDB. Each with "how to get this key" help text and a Verify button.
7. **Artwork** — "Download artwork now?" (Fast queue only by default; videos optional) with Wi-Fi-only toggle.
8. **Done** → Home. Scraping continues in the background (Downloads page).

## Scanner rules (C++, `deckos.library`)
- Walk with `QDirIterator` on real paths when All files access is granted; with SAF, batch-query `DocumentsContract` children via JNI (avoid per-file round trips).
- **System detection** by folder name aliases (case/punctuation-insensitive: `psx`, `ps1`, `playstation`, `PlayStation 1` → `psx`), then by extension set; ambiguous extensions (`.iso`, `.bin`, `.chd`, `.cue`) resolved by folder first, content sniff second (e.g. PS2/PSP/GameCube/Wii disc headers, Saturn/Sega CD IP.BIN, PS1 `SYSTEM.CNF`).
- **Multi-disc**: if an `.m3u` exists, show only the `.m3u`; otherwise group `(Disc 1)`/`(Disc 2)` into one game with multiple files (Pegasus supports multi-file games). `.cue` hides its `.bin` tracks; `.gdi` hides tracks.
- **Folder games**: PS3 (`PS3_GAME/PARAM.SFO` or `*.ps3` folders), Wii U, Windows/PC game folders, ScummVM — treat folder as one game.
- **Exclude**: BIOS/firmware lists (by name and known hashes), save files, `.txt/.nfo/.jpg` sidecars, hidden/system dirs, `media/` and `DeckOS/` dirs.
- **Name cleanup** for display: strip No-Intro/Redump tags (`(USA)`, `[!]`, `(Rev 1)`) into separate fields (region, revision), keep original filename for matching. Region preference setting for duplicates (hide/show duplicates).
- **Incremental**: store path, size, mtime in `games_identity`; rescan only changed dirs; background rescan on app start and via Settings → Library → Rescan. Never block the UI; show progress in the top bar.
- **Identity hashing** (CRC32/MD5/SHA1 + RA hash) is lazy and cached: computed when needed by RA/scraper, skip for huge files unless the system needs it (see RA spec).

## Output: still Pegasus-compatible
- Generate one `metadata.pegasus.txt` per system into the DeckOS data dir (`generated/<system>/metadata.pegasus.txt`) with `collection`, `shortname`, `extensions`/`files`, `launch` (resolved command, see emulator spec), and game entries. Header comment: `# AUTO-GENERATED by DeckOS — edits here are overwritten. Put your changes in metadata.user.pegasus.txt`.
- User override files and extra Pegasus game dirs (Settings → Library → Advanced → Additional game folders) are loaded after generated ones and win.
- Existing users: on first run, detect existing Pegasus game dirs/metadata and offer "Import my Pegasus setup".

## Systems catalog (`catalog/systems.json`)
One entry per system: `id`, display name, short name, manufacturer, year, folder aliases, extensions, `ra_console_id`, `screenscraper_id`, `igdb_platform_id`, `tgdb_platform_id`, libretro thumbnail repo name, SteamGridDB hints, default RetroArch core(s), icon asset, accent color, hash method notes.
Build it from authoritative sources and record where each field came from: RA `API_GetConsoleIDs`, ScreenScraper `systemesListe`, IGDB platforms, libretro-thumbnails repo list, ES-DE / Daijishō platform definitions for aliases/extensions (facts only; check licenses before copying files). See `catalog/systems.example.json` for the shape.
